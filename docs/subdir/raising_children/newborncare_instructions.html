新生児お世話 手順書（詳細版） 退院〜生後1か月

※この文書は「誰がやっても同じ結果になる」ことを目的に、具体的な操作・コツ・失敗例を含めて記載。

0. 最初に準備する環境

室内環境

  • 室温：20〜24℃（冬は22〜24℃寄り、夏はエアコン直風を避ける）
  • 湿度：40〜60%（乾燥＝鼻づまり・哺乳不良の原因）
  • 照明：夜間は暖色の間接照明のみ（覚醒防止）
新生児は体温調節が未熟。大人が「少し涼しい」と感じる程度が適切。

作業ステーション（固定位置に設置）

  • おむつ一式
  • ガーゼ5枚以上
  • 清潔綿
  • 体温計
  • 着替え2セット
  • 防水シート
毎回探すと事故率が上がる。置き場は固定。

1. 抱っこ（最重要スキル）

基本姿勢

  1. 必ず手洗い（石鹸20秒）
  2. 片手で首の後ろ〜頭を支える
  3. もう片手でお尻をすくう
  4. 自分の胸に密着させる

コツ

  • 「持ち上げる」ではなく「自分に引き寄せる」
  • 首を空中に浮かせない
  • 不安定な高さでの移動禁止（特にソファ前）
落下事故の最多は「ちょっとだけ」の油断。

2. 授乳（完全手順）

授乳前チェック

  1. おむつ確認（先に替える）
  2. 覚醒状態にする（足裏を軽く触る）
  3. 口をモグモグしたら授乳開始サイン

母乳の具体操作

  1. 乳首だけでなく乳輪まで深く含ませる
  2. 鼻が乳房に埋まらない角度に調整
  3. 顎が規則的に動いているか確認
乳首が痛い＝浅吸い。ほぼ確実に失敗しています。

ミルク調乳（重要：感染対策）

  1. 手洗い
  2. 哺乳瓶を消毒
  3. 70℃以上のお湯を入れる
  4. 粉ミルクを規定量投入
  5. 流水で冷却→人肌確認（手首内側）
ぬるま湯で調乳は細菌増殖リスクあり。

げっぷ（3パターン）

  • 縦抱き肩の上
  • 膝上座位
  • うつ伏せ前腕抱き
出ない場合：5分で終了してOK（必須ではない）。

3. 泣いたときのトラブルシュート（順番固定）

  1. おむつ
  2. 空腹
  3. 暑い／寒い
  4. 眠い
  5. げっぷ
  6. 抱っこ要求

あやし方（5S）

  • Swaddle：おくるみ
  • Side：横向き抱き
  • Shush：耳元ホワイトノイズ
  • Swing：小刻み揺れ（大きく揺らさない）
  • Suck：おしゃぶり
激しい揺さぶりは乳児揺さぶられ症候群の原因。

4. おむつ替え（失敗例つき）

  1. 新しいおむつを先に敷く
  2. 汚れを前→後ろで拭く
  3. 乾燥させる（これ重要）
  4. テープ固定

よくある失敗

  • すぐ閉じる→おむつかぶれ
  • 男児で上向き→漏れる

5. 沐浴（分単位）

  1. 準備（3分）衣類・タオル・保湿を並べる
  2. 入浴（5〜7分）
  3. 保湿（2分以内）
  4. 着衣（3分）

洗う順番

  1. 顔（石鹸なし）
  2. 頭
  3. 首のしわ
  4. 腕・手
  5. 胸腹
  6. 陰部
  7. 背中
首のしわの洗い残し＝湿疹の最大原因。

6. 睡眠安全ルール

  • 仰向け固定
  • 枕なし
  • ぬいぐるみ禁止
  • 同室別寝具
添い寝中の圧迫・窒息事故は実在します。

7. 毎日観察（異常の早期発見）

項目正常異常
体温36.5〜37.538以上
呼吸40〜60/分陥没呼吸
尿6回以上/日半日出ない
便黄色白色

8. 受診が必要な症状

  • 発熱
  • 哺乳拒否
  • ぐったり
  • 呼吸苦
  • 痙攣

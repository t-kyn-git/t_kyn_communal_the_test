Policy for Using Generative AI in Coding Automation

A role-based workflow for Claude, Codex, and ChatGPT, using local folders and temporary branches to keep code changes controlled and testable.

1. Overall Policy

Priority

Claude > Codex > ChatGPT > Copilot > Google AI Studio = Gemini

Core Principle

Each AI has a fixed role, and editing scope, verification steps, and branch handling are standardized.

Safety

Temporary branches and tests are mandatory to avoid direct changes to the main line.

Branch names can be standardized according to the operation. The key is to separate workspaces by AI and promote changes only after verification.

3. Claude Usage

  • Purpose: coding automation. Use it when official documentation needs to be checked as well.
  • Model: Sonnet 4.6 as the highest-performance model assumed here.
  • MCPs: Context7 and FileSystem.
  • Best use case: file creation and modification should generally be done in Claude Desktop.
  • Rate limits vary by situation, so keep the editing scope narrow.

4. Codex Usage

  • Purpose: coding automation. Suitable for tasks that do not require checking official documentation first.
  • Model: GPT-5.4 as the highest-performance model assumed here.
  • MCPs: Context7 and FileSystem.
  • Operation: create a temporary branch, commit changes, verify them, and delete the branch once confirmed.
  • Install Microsoft.VCRedist.2015+.x64 in advance because Codex may require it to launch.

Installation example

winget install --id Microsoft.VCRedist.2015+.x64 -e

5. Branch Operation Rules

  • RemotoTmpBranch is treated as the intermediate workspace for Codex and ChatGPT.
  • RemotoBranch is treated as the verification stage before upstream integration.
  • RemotoBranch is deleted periodically so that unnecessary history does not accumulate.
  • Only changes that pass unit tests and merge tests are allowed to proceed.

6. Additional Notes

  • Claude is the primary tool for design and edits.
  • Codex is best for short, iterative implementation assistance.
  • ChatGPT is used mainly for organizing, transforming, and extracting materials.

Ansible Compose Architecture

This configuration shows an Ansible container managing multiple node containers.
Each node provides services on its own port, and the Ansible container controls them.
Adding new nodes in the future is also easy.
For example, if a new node called NodeX is added, it will be reflected in the configuration diagram as follows.
This indicates that the added node will be managed by the Ansible container.
This improves the scalability and flexibility of the system.

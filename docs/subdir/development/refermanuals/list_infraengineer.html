インフラエンジニアが知っておくべきサイトまとめ（詳細版）

システムの基盤を支えるインフラエンジニアには、OS、ネットワーク、データベースといった要素技術に対する深い理解が不可欠です。ここでは、各分野の仕様理解や問題解決に役立つ専門的なサイトを中心にまとめました。

OSの細かい仕様

OSの挙動を正確に理解するための、一次情報に近いサイトです。

  • Microsoft Learn (旧: Microsoft Docs): Windows ServerやAzureに関する公式ドキュメント。機能の仕様、設定方法、PowerShellのコマンドレットまで、あらゆる情報が網羅されています。
  • The Linux Kernel Archives: Linuxカーネルの公式サイト。カーネルのソースコードや最新バージョンのリリースノートなど、Linuxの最も深い部分の情報源です。
  • ArchWiki: 特定のLinuxディストリビューションに偏らない、非常に詳細で網羅的な情報がまとまっています。トラブルシューティングの際に特に役立ちます。
  • man7.org, online linux manual pages: Linuxのmanコマンドで表示されるマニュアルのオンライン版。システムコールやライブラリ関数の詳細な仕様を確認する際に必須です。
  • Red Hat Customer Portal: Red Hat Enterprise Linuxに関する公式ナレッジベースやドキュメントが豊富です。エンタープライズ環境での運用ノウハウが多く含まれます。

ネットワーク

プロトコルの仕様から実践的な設計まで、ネットワーク技術を深く学ぶためのサイトです。

  • IETF (Internet Engineering Task Force): インターネット技術の標準仕様であるRFC (Request for Comments) を策定している団体。TCP/IPなど各種プロトコルの正確な仕様を確認する際の最終的な情報源です。
  • @IT > Master of IP Network: ネットワーク技術の基礎から応用までを体系的に解説した長期連載。ネットワークの教科書として非常に価値が高いです。
  • ShowNet (Interop Tokyo): 国内最大級のICTイベントで構築される巨大ネットワークの設計情報や構築・運用ログが公開されています。最先端の技術を組み合わせた実践的な構成を学べます。
  • JPNIC (日本ネットワークインフォメーションセンター): 日本のIPアドレスやドメイン名を管理する組織。インターネットの基盤技術に関する解説や統計情報が掲載されています。
  • Cisco Blogs: ネットワーク機器最大手であるシスコの公式ブログ。最新のネットワークトレンドやセキュリティに関する深い洞察が得られます。

データベース

データベースのアーキテクチャやパフォーマンスチューニングに関する情報源です。

  • PostgreSQL Documentation: PostgreSQLの公式ドキュメント。非常に詳細かつ分かりやすいと定評があり、データベースの内部構造を理解するためにも役立ちます。
  • MySQL Server Blog: MySQL開発チームによる公式ブログ。新機能の解説や内部アーキテクチャに関する深い情報が得られます。
  • DB-Engines: 様々なデータベース管理システムの人気ランキングやトレンドを比較できるサイト。技術選定の際に参考になります。
  • gihyo.jp > データベース: 技術評論社のWebサイト。データベースの基礎から応用まで、多くの優れた連載記事が掲載されています。
  • Oracle Technology Network (Japan): Oracle Databaseに関する技術資料やマニュアルが豊富に揃っています。

クラウド・コンテナ技術

現代のインフラに必須のクラウドとコンテナに関する公式サイトです。

  • AWS Black Belt Online Seminar: AWSの各サービスについて、日本のソリューションアーキテクトが詳細に解説する資料と動画。非常に分かりやすく実践的です。
  • Kubernetes Documentation: コンテナオーケストレーションの標準であるKubernetesの公式ドキュメント。コンセプトから運用方法まで網羅されています。
  • Docker Documentation: コンテナ技術の基本であるDockerの公式ドキュメント。
  • HashiCorp Developer: TerraformやVaultなど、IaC (Infrastructure as Code) ツールを提供するHashiCorp社の開発者向けサイト。チュートリアルが充実しています。

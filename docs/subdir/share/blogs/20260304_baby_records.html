息子との日々のきろく

🤰 妊娠期間

妊娠初期はつわりがかなりひどく、妻にとって辛い日々が続いた。

安定期に入ると食欲が戻り、もりもり食べられるように。

胎動は夜になると活発になることが多く、お腹の中でも夜型だったのかも。

🏥 出産

無痛分娩の予定で臨んだが、途中で破水。

さらに臍の緒が赤ちゃんに絡まっていることが判明し、自然分娩では難しいと判断。

急遽、緊急帝王切開で出産することになった。

予定外の展開に不安と緊張でいっぱいだったが、母子ともに無事に乗り越えてくれた。
本当によく頑張ってくれた。

💭 パパの心情

生まれてきた息子の顔を初めて見たとき、言葉にならなかった。

緊急帝王切開という想定外の展開に、手術室の外で待っている間は気が気でなかった。

「育休を取って絶対に支えよう」と、そのとき強く思った。

🏠 育児休職中に担当したこと

```

家のこと

やること担当
洗濯パパ
掃除パパ
皿洗いパパ
料理ママ

産後の妻が体を動かせる範囲で料理を担当してくれており、それ以外の家事はパパが引き受けた。

育児

やること担当
寝かしつけパパ
おむつ替え→ミルクパパ
おむつ替え→母乳ママ
沐浴交代制
夜のワンオペパパ

おむつ替えと授乳はセットで担当。パパのときはおむつ替え→ミルク、ママのときはおむつ替え→母乳という流れで対応している。

沐浴は交代制で、お互いに慣れながら取り組んでいる。

夜間はママを休ませるためパパがワンオペで対応。泣き声に起きて、ミルクをあげて、寝かしつけて——気づけば朝になっていることも。

```

😅 苦労したこと

おむつ替え中のおしっこシャワーが連発。油断した瞬間にやられる。

さらにミルクの吐き戻しも重なり、1日に何度も着替えるはめになった——息子も、パパも。

洗濯物の山を見ながら「また増えた…」と苦笑いしつつ、それでも憎めないのが不思議なところ。

✨ 一言

大変なことも多いけれど、息子の顔を見るたびにすべて吹き飛ぶ。

この時間は一生に一度。全力で楽しもうと思う。
